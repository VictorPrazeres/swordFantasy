> **swordFantasy** é um projeto de estudos focado no desenvolvimento de jogos (*Game Dev*) estilo **Top-Down RPG/Action**, construído com a **Godot Engine** utilizando **GDScript**.

---

## 📌 Sobre o Projeto

Este repositório tem como objetivo documentar o aprendizado prático e a evolução na criação de mecânicas essenciais para jogos 2D Top-Down. O projeto serve como laboratório para teste de arquitetura de cenas, física 2D, máquinas de estados, sistemas de combate e integração de animações na Godot Engine.

---

## ✨ Funcionalidades e Mecânicas

- [x] **Movimentação Top-Down:** Controle em 8 direções com aceleração e colisão fluida.
- [x] **Sistema de Combate:** Ataques com espada utilizando caixas de colisão (`Area2D` / `CollisionShape2D`).
- [x] **Animações e Sprites:** Sincronização de estados (Idle, Walking, Attack).
- [x] **Cenários & Tilemaps:** Construção de mapas estruturados utilizando o sistema de `TileMapLayer`.
